Persistent goal: make the existing animation workflow usable through a coherent Studio frontend and its agent tools.

Completion criteria:

- Inspector, transform controls, library, curves and layers do not overlap essential controls at supported window sizes.
- Hover expansion preserves viewport/timeline geometry; a deliberate pin may reserve space.
- Primary labels and controls are readable, with contextual advanced controls and clear save semantics.
- Rig framing uses bounds and viewport aspect, with readable preview lighting.
- Timeline height can be adjusted without breaking track/ruler/playhead alignment or input routing.
